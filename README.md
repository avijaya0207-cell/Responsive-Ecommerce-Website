🛍️ ShopEase – Responsive E-Commerce Website

📌 About the Project

ShopEase is a responsive E-Commerce website developed using HTML, CSS, JavaScript, and Firebase.

✨ Features

- Responsive website design
- Modern user interface
- Product listing from Firebase Firestore
- Add to Cart functionality
- Remove items from Cart
- Automatic Cart Total calculation
- Checkout functionality
- Save orders to Firebase Firestore

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase Firestore
- GitHub Pages
